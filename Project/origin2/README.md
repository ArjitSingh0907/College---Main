## ☄️ Astronomical UI/UX & Visual Physics

- **Liquid Obsidian Canvas:** Deep cosmic aesthetic featuring adaptive glassmorphism tokens, sub-pixel frosted blur rings (`backdrop-filter: saturate(160%) blur(20px)`), and celestial ambient glow horizons.
- **Dual-Core Starfield Engine:** Hardware-accelerated HTML5 canvas calculating real-time 3D starfield hyperdrive trajectories based on viewport depth ($Z$-axis projection).
- **Plasma Comet Pointer:** Zero-lag custom pointer physics rendering a trailing particle wake with dynamic air-resistance decay and scroll-induced solar wind deflection.
- **Zero-Reflow Split Island Navigation:** Dynamic One UI 9.5-inspired dual capsule dock that detects hero threshold crossing and snaps into a docked state without viewport jump.
- **3D Orbital Flippable Domains:** Six interactive vertical cards equipped with double-sided $Y$-axis CSS 3D transforms, keeping embargoed problem statements encrypted until orbital unlock.

## 🛰️ Dual-Portal System

ORIGIN '26 operates as a unified platform supporting two independent mission cohorts:

1. **Student Registration Gateway (`index.html`)**
   - Direct QR routing for rapid mobile enrolment.
   - Comprehensive timeline visualization from embargo lift to sprint finale.
   - Architectural pathway guides for software engines vs. cyber-physical hardware tracks.

2. **Corporate Challenge Portal (`post-ps.html`)**
   - Dedicated briefing portal for enterprise sponsors, brands, and technical mentors.
   - High-throughput ingestion form capturing up to 5 modular problem statements and company constraints.
   - **Client-Side Corporate Domain Gatekeeper:** Real-time domain verification that blocks generic consumer mail providers (`@gmail.com`, `@yahoo.com`, `@outlook.com`, etc.) to authenticate corporate stakeholders.

## 🛠️ Tech Stack & Infrastructure

### Client Horizon
- **Semantic Engine:** HTML5 with strict semantic scaffolding and ARIA accessibility standards.
- **Visual Design System:** Vanilla CSS3 featuring squircle primitives, fluid typography scales, and CSS custom property matrices.
- **Particle & Physics Layer:** Vanilla JavaScript (ES6+) executing continuous `requestAnimationFrame` render loops with zero framework overhead.
- **Data Decoupling:** Dynamic data-driven content pipeline managed centrally via `data.js`.

### Ground Station API & Storage
- **Runtime Environment:** Node.js & Express REST ingestion engine.
- **Relational Storage:** MySQL database with parameterized queries and index structures (`schema.sql`).
- **Security & Integrity:** Sanitized multi-variable payloads, strict CORS headers, and cross-field corporate domain validation.
